# Figures for the completed follow-up

Generated by [`src/report_followup.py`](../../../src/report_followup.py) from the completed run records. Each figure is supplied as PNG (220 dpi), PDF and SVG. None uses a PowerPoint chart object. The corresponding [detailed report](../../../DETAILED_FOLLOWUP_REPORT.md) and [slide revision plan](../../../presentation/representation-study/REVISION_PLAN.md) contain captions and interpretation.

| Figure | Preview | Description |
|---|---|---|
| 1 | [Data context](fig01_data_context.png) | Test base rates on a log axis and daily novelty prevalence. Time and novelty partitions overlap. |
| 2 | [Relationship example](fig02_relationship.png) | Illustrative ordered transfers; counts precede each target, ports are zero-based. This is a definition example, not measured data. |
| 3 | [Paired effects](fig03_paired_effects.png) | The primary addition and two secondary contrasts. Diamonds and intervals use the original nominal paired t analysis; dots show individual seeds. |
| 4 | [Error decomposition](fig04_error_decomposition.png) | Post-hoc descriptive B−A changes in TP and FP by novelty stratum; dots are paired seeds and diamonds are means. No new intervals or tests. |
| 5 | [Sensitivity views](fig05_sensitivity.png) | All prespecified fixed-checkpoint views plus the primary selection and days 8–9. The same data and models are reused. |
| 6 | [Validation trajectories](fig06_validation_trajectories.png) | Individual AP curves and selected checkpoints. The black five-seed mean ends at epoch 20, before seed composition can change. |
| 7 | [Linear probes](fig07_probe.png) | Predicting novelty from raw inputs or frozen representations. AP prevalence baseline is shown; decodability does not identify causal AML use. |

F1 and AML AP differences are percentage points. Probe AP/AUROC use the 0–1 scale. Alert changes are transaction counts at model-specific validation-selected thresholds, not investigation cases or results at a fixed workload. The script records source hashes and descriptive calculations in [`analysis_notes.json`](../analysis_notes.json).

Regenerate from the repository root with `python src/report_followup.py` (NumPy and Matplotlib required). This reads saved JSON, creates figures, and writes descriptive data; it does not fit models, refit probes, select checkpoints, or add significance tests.
